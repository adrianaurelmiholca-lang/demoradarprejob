# PREJOB RADAR

Demonstrație logică PREJOB pentru explorarea legăturilor dintre activități, competențe, educație, ocupații și economia reală.

## Statut

Faza 0. Datele și traseele sunt ilustrative. Nu există analiză AI live, profilare, baze de date conectate sau recomandări individuale.

## Principiu

Recomandă explorarea, nu decide traseul. Structurează, nu diagnostichează. Orientează, nu înlocuiește omul relevant.

## Publicare

GitHub este sursa master și istoricul versiunilor. Cloudflare Workers Static Assets este runtime-ul canonic ales pentru PREJOB RADAR și pentru aplicațiile PREJOB care vor primi ulterior logică de backend. GitHub Pages rămâne potrivit pentru documentele strict statice, iar publicarea Netlify este în retragere controlată.

## Statutul relațiilor din demo

Etichetele din interfață indică surse planificate, nu proveniență deja validată și nu niveluri de încredere calculate. Toate relațiile sunt marcate explicit drept ipoteze demonstrative, nevalidate DBP. Un nivel de încredere per relație va fi afișat numai după aprobarea protocolului DBP și existența dovezii aferente fiecărei relații.
